## 🧩 App Features

- Menggunakan layout widget: **Column**
- Menggunakan **Container** untuk styling
- Menggunakan **Card** dan **ListTile** untuk informasi kontak
- Tema global dengan **ThemeData** dan **custom font (Poppins)**
